\doxysubsection{Detailed Description}
Flat attribute storage using \doxylink{classtinyobj_1_1_typed_array}{Typed\+Array} (arena-\/backed). All arrays are allocated from the \doxylink{structtinyobj_1_1_opt_result}{Opt\+Result}\textquotesingle{}s arena.

Unlike \doxylink{structtinyobj_1_1basic__attrib__t}{basic\+\_\+attrib\+\_\+t} (used by Load\+Obj\+Opt), optional arrays like vertex\+\_\+weights, texcoord\+\_\+ws, colors, and smoothing\+\_\+group\+\_\+ids are only allocated when the input actually contains the corresponding data. Check .empty() before accessing.
