==\texorpdfstring{$>$}{>}\texorpdfstring{$>$}{>}========= Optimized API (C++11 required) ============================

Optional compile options (all DISABLED by default — define the macro to opt in): TINYOBJLOADER\+\_\+\+USE\+\_\+\+MULTITHREADING -\/ multi-\/threaded parsing TINYOBJLOADER\+\_\+\+USE\+\_\+\+SIMD -\/ SIMD-\/accelerated line scanning (SSE2/\+\+AVX2 on x86, NEON on ARM) TINYOBJLOADER\+\_\+\+ENABLE\+\_\+\+EXCEPTION -\/ throw std::\+bad\+\_\+alloc on allocation failure instead of returning nullptr

With none of these defined, the parser runs single-\/threaded, scalar, and exception-\/free. These features require C++11 or later. Arena-\/based memory allocator for reduced allocation overhead when loading huge meshes. Memory is freed in bulk when the arena is destroyed or \doxylink{classtinyobj_1_1_arena_allocator_ab18af8dabaf88c93f73d47740ce1b995}{reset()}. Individual deallocate() calls are no-\/ops.
