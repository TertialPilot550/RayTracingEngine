◆ float_cache

bool tinyobj::OptLoadConfig::float_cache

Enable trie-based float string → value cache. Speeds up files with many repeated coordinate values (e.g. "0.0", "1.0").

◆ float_cache_max_nodes

int tinyobj::OptLoadConfig::float_cache_max_nodes

Maximum trie nodes per thread (controls cache memory). Each node is ~36 bytes, so 1024 nodes ≈ 36 KB (fits in L1 cache).

◆ fp32_cache

bool tinyobj::OptLoadConfig::fp32_cache

Use fp32-length keys for the float cache (max 8 chars). When true, only tokens up to float::digits10 + 2 characters are cached. When false, uses real_t::digits10 + 2 (longer keys, fewer hits). Has no effect when float_cache is false.

◆ num_threads

int tinyobj::OptLoadConfig::num_threads

Number of threads. -1 = hardware_concurrency, 0 or 1 = single-threaded. Effective only when TINYOBJLOADER_USE_MULTITHREADING is defined.
