Detailed Description

template<typename Alloc = std::allocator<char>>
struct tinyobj::basic_attrib_t< Alloc >

Template attrib type supporting custom allocators. Flat arrays: vertices(xyz), normals(xyz), texcoords(uv). Note: Alloc must be default-constructible (stateless). For stateful allocators like arena_adapter, construct vectors individually with an allocator instance.
