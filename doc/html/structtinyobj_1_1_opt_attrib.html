Detailed Description

Flat attribute storage using TypedArray (arena-backed). All arrays are allocated from the OptResult's arena.

Unlike basic_attrib_t (used by LoadObjOpt), optional arrays like vertex_weights, texcoord_ws, colors, and smoothing_group_ids are only allocated when the input actually contains the corresponding data. Check .empty() before accessing.
