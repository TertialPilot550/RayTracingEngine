Detailed Description

template<typename Alloc = std::allocator<char>>
struct tinyobj::basic_mesh_t< Alloc >

Template mesh type supporting custom allocators. Note: Alloc must be default-constructible (stateless). For stateful allocators like arena_adapter, construct vectors individually with an allocator instance.
